# Thorium Patches

All Thorium source modifications applied to a clean Chromium tree during a
build. The apply order is defined by two series files:

| File | Role |
|------|------|
| [`series`](./series) | Thorium-owned patches — applied after `overlay/` |
| [`series.external`](./series.external) | Whitelist of external patches (ungoogled-chromium-windows, cromite) — applied first |

## Layout

| Path | Files | Contents |
|------|-------|----------|
| `series` | 138 entries | 137 Thorium patches + 1 external patch, in apply order |
| `series.external` | 35 entries | 14 `#[main]` + 21 `#[windows]` (0 active `#[cromite]`) |
| `thorium/external_temp/` | 1 | Patches taken from external projects, conflict-fixed locally |
| `thorium/fixes/` | 7 | Build fixes required by the external patch set |
| `thorium/original/` | 126 | Thorium patches ported from upstream Thorium-LTS `other/` |
| `thorium/new/` | 3 + 1 template | Locally maintained / build-time generated patches |

Removed during the M138 → M150 migration, do not recreate:

- `thorium/fixes_upstream/` — crash fixes were folded into `thorium/fixes/` or upstream.
- The `thorium/new/` merged multi-file patch set (`thorium-ui.patch`,
  `thorium-build-config.patch`, …) — replaced by per-theme patches in
  `thorium/original/`.

## Application Order

`build.py` runs a single patch pipeline (`_apply_all_patches`):

1. **External patches** — every entry of `series.external`, resolved against a
   per-section base directory (see below).
2. **Widevine CDM version injection** — CDM version header from the overlay manifest.
3. **Overlay overrides** — `overlay/` is copied into the source tree.
4. **SafeBrowsing patch regeneration** — `patch_scripts/extract_safebrowsing_patches.py`
   rewrites `thorium/fixes/autogenerated_remove-safebrowsing-prefs-deps.patch`.
5. **Thorium patches** — every entry of `series`, in file order.
6. **Brand string sync** — GRD/GRDP → XTB brand substitutions (`patch_scripts/`).

Inside `series` the order is:

```
thorium/external_temp/   (GPC)
thorium/fixes/           (SafeBrowsing deps, GPC strings, UI removal, VR, …)
   └─ one external patch is interleaved here (move-js-optimizer-unfamiliar-sites)
thorium/original/        (patchThor order first, then theme categories 05–80)
thorium/new/             (API keys injection, Noto Color Emoji, build output)
```

Ordering constraints that must be preserved:

| Constraint | Why |
|---|---|
| `autogenerated_remove-safebrowsing-prefs-deps.patch` before `move-js-optimizer-unfamiliar-sites.patch` | The latter fixes build errors introduced by the former |
| GPC patch before `fix-gcp-grdp-strings.patch` | GRDP resources are added by the GPC patch |
| `views-menu-delay.patch` before `thorium-2024-ui-core.patch` | Both touch the same menu-delay call site |
| `thorium-set-api-keys.patch` near the end | Generated file must exist before it is applied |

## External Patches (`series.external`)

Section markers select the base directory each entry is resolved against:

| Marker | Base directory | Count |
|--------|----------------|-------|
| `#[main]` | `<ungoogled-submodule>/ungoogled-chromium/patches/` | 14 |
| `#[windows]` (default) | `<ungoogled-submodule>/patches/` | 21 |
| `#[cromite]` | `cromite/build/patches/` | 0 (both entries commented out pending conflict fixes) |

`#[main]` supplies the prerequisites Thorium depends on (missing dependencies,
SafeBrowsing removal, Privacy Sandbox disable, Manifest V2, AI / AI-search-shortcut
removal, download quarantine removal, navigation-source-param removal).
`#[windows]` supplies the Windows-only build, linking, RC and mini_installer fixes.

Intentionally **not** applied, documented in the file header:

| Patch | Reason |
|-------|--------|
| `windows-disable-encryption.patch` | Modifies the ungoogled-only `ungoogled_platform_flag_entries.h`; Thorium ships its own `disable-encryption` handling instead |
| `windows-disable-machine-id.patch` | Same dependency on the ungoogled-only header |
| `Enable-Global-Privacy-Control.patch`, `Override-the-MV2-deprecation.patch` (cromite) | Temporarily disabled — conflicts with this baseline; the GPC patch lives in `thorium/external_temp/`, and MV2 is kept by `extensions-manifestv2.patch` from `#[main]` |

To enable or drop an external patch, edit `series.external` only — `build.py`
reads the file, so no code change is needed.

removed, so they are not re-added by mistake. Summary:

  `new-tab-button-middle-click`, `transparent-tabs`, `windows-menu-style-overrides`.

  `disable-privacy-sandbox`, `disable-download-quarantine`,
  `allow_manifest_v2_extensions`, `chrome-web-store-protection`,
  `allow-insecure-downloads`, `thorium-chrome-build-targets`.
- **Replaced by other Thorium patches** — `thorium-default-api-keys` (now the
  `thorium-set-api-keys` prepatch mechanism), `GPC.patch`,
  `thorium-2024-ui.patch` (split into `thorium-2024-ui-core` +
  `thorium-2024-menu-interactions`), `llvm-optimized-avx2-build`
  (merged into `llvm-optimized-toolchain-build`).
- **Android-only** — `android-thorium-branding`, `android-extensions-support`,
  `enable-extension-in-incognito`.
