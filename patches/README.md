# Thorium Patches

This directory contains all Thorium patches that are applied on top of a clean
Chromium source tree during the build. The application order is defined in
[`series`](./series) and follows the structure documented below.

## Layout

| Path | Contents |
|------|----------|
| [`series`](./series) | Master patch list — all patches in apply order |
| [`series.external`](./series.external) | External patches from multiple projects (ungoogled-windows, cromite, etc.) |
| `thorium/fixes_upstream/` | Upstream crash fixes (can be removed once merged) |
| `thorium/fixes/` | SafeBrowsing dependency patches + misc standalone fixes |
| `thorium/original/` | Multi-file patches ported from the original Thorium project's `other/` directory |
| `thorium/new/` | Merged multi-file patches generated by diffing Thorium source files against Chromium baseline |

| `fix_disable_aero_crash.patch` | Crash when Aero is disabled on Windows |
| `fix_file_dialog_crash.patch` | File dialog crash |
| `fix_wayland_scale_crash.patch` | Wayland scale-related crash |
| `fix_setting_popover_invoker_crash.patch` | Settings popover invoker crash |
| `fix_drag_and_drop_on_wayland.patch` | Drag-and-drop on Wayland |

### Merged New Patches (`new/`)

These patches were auto-generated by diffing Thorium's modified source files
against a clean Chromium baseline, then merged into multi-file patches by
purpose. Each patch covers a logical theme.

| Patch | Purpose |
|-------|---------|
| `thorium-compiler-simd.patch` | Compiler flags and SIMD instruction set configuration across all platforms (android, arm, mac, win, v8, clang) |
| `thorium-build-config.patch` | Build system changes — Ash webui, toolchain, dependencies, Widevine, V8 snapshot, sandbox |
| `thorium-ui.patch` | UI customization — tab strip, toolbar buttons, startup infobars, omnibox, themes, icons, X11/GTK |
| `thorium-privacy.patch` | Privacy defaults — DoNotTrack, IP Protection, disable ad-auction signals, disable alternate error pages |
| `thorium-media-codecs.patch` | Media support — HEVC software decoding, AC3/EAC3 audio, accelerated video encoding, tab muting |
| `thorium-quarantine-removal.patch` | Remove the quarantine service dependency from downloads, file system access, and PPAPI |
| `thorium-extensions-mv3.patch` | Extension system — keep Manifest V2 enabled, increase declarativeNetRequest limits, silence MV2 deprecation warnings |
| `thorium-dns-network.patch` | DNS/network — secure DoH by default, custom DNS config flag, LOAD_MINIMAL_HEADERS for privacy, RSA 2048 default, saveable URL schemes |
| `thorium-downloads.patch` | Download behavior — allow insecure downloads flag, download UI and target handling |
| `thorium-encryption-machineid.patch` | Disable OS-level encryption (DPAPI) and machine ID collection via flags |
| `thorium-history-preferences.patch` | Preferences — show bookmark bar by default, keep-all-history flag, disable background mode, unmark Ubuntu 18.04 as obsolete |
| `thorium-telemetry-flags.patch` | Telemetry and flags — disable variations seed fetching, block feature promos, reader mode on desktop, Thorium flag entries |
| `thorium-gpu-features.patch` | GPU/Vulkan — VAAPI config, Vulkan ICD paths in GPU sandbox |
| `thorium-misc-fixes.patch` | Miscellaneous — custom NTP flag, audio sandbox syscall, WebAudio no-gesture, Windows MS signed binary bypass |

## Patch Application Order

The patches are applied in the order listed in [`series`](./series):

1. **Upstream fixes** (`fixes_upstream/`) — crash fixes, removable once upstreamed
2. **SafeBrowsing deps** (`fixes/`) — dependency patches for building without SafeBrowsing
3. **Original Thorium patches** (`original/`) — multi-file patches ported from Thorium's setup.sh
4. **Merged new patches** (`new/`) — generated and merged patches grouped by purpose
