# Thorium Patches

This directory contains all Thorium patches that are applied on top of a clean
Chromium source tree during the build. The application order is defined in
[`series`](./series) and [`series.external`](./series.external).

## Layout

| Path | Contents |
|------|----------|
| [`series`](./series) | Master patch list — all patches in apply order |
| [`series.external`](./series.external) | External patches from multiple projects (ungoogled-windows, cromite, etc.) — applied before `series` during build |
| `thorium/external_temp/` | Patches temporarily extracted from external repos and fixed for conflicts on current Chromium baseline |
| `thorium/fixes_upstream/` | Upstream crash fixes — can be removed once merged upstream |
| `thorium/fixes/` | SafeBrowsing dependency patches, GPC fixes, UI removal, and misc standalone build fixes |
| `thorium/original/` | Multi-file patches ported from the original Thorium project's `other/` directory |
| `thorium/new/` | Merged multi-file patches generated by diffing Thorium source files against Chromium baseline |

## Patch Categories

### External Temp (`external_temp/`)

Patches pulled from external projects (cromite, etc.) that had conflicts with the current
Chromium baseline and were manually fixed here. They are listed at the top of `series`
and applied first.

| Patch | Purpose |
|-------|---------|
| `Enable-Global-Privacy-Control.patch` | Global Privacy Control (Do Not Sell / GPC header) — migrated from `original/GPC.patch` |

### Upstream Crash Fixes (`fixes_upstream/`)

Patches that fix crashes in Chromium code. These should be removed once the
fixes are merged upstream.

| Patch | Fixes |
|-------|-------|
| `fix_dangling_pointer_tooltip.patch` | Dangling pointer in tooltip code |
| `fix_disable_aero_crash.patch` | Crash when Aero is disabled on Windows |

### Standalone Fixes (`fixes/`)

| Patch | Purpose |
|-------|---------|
| `autogenerated_remove-safebrowsing-prefs-deps.patch` | Auto-extracted SafeBrowsing preference dependencies (from ungoogled-chromium) |
| `fix-gcp-grdp-strings.patch` | Fix GPC grdp string resources for `Enable-Global-Privacy-Control.patch` |
| `remove-uneeded-ui.patch` | Remove Privacy Guide entry points, Safety Hub sidebar entry, and password leak detection toggle |
| `remove-safebrowsing-prefs-deps.patch` | Manual SafeBrowsing preference dependency cleanup |
| `fix-building-device-vr.patch` | Fix VR device build with `enable_vr=true` |
| `fix_absl_undefined_symbol.patch` | Fix undefined absl symbol on Windows debug builds |

In addition, the series includes one external patch between the fixes above:
- `../ungoogled-chromium-windows/.../move-js-optimizer-unfamiliar-sites.patch` — pulled from the ungoogled-chromium-windows submodule via `series.external`.

## External Patches (`series.external`)

The build system applies external patches from `series.external` before the
patches listed in `series`. This file is organized into sections:

- **`#[main]`** — Patches from `ungoogled-chromium/patches/` (ungoogled-core + inox-patchset):
  - Missing dependencies, SafeBrowsing removal, Privacy Sandbox disable, ManifestV2,
    AI search shortcuts disable, download quarantine disable
- **`#[windows]`** — Patches from `ungoogled-chromium/patches/` (Windows-specific):
  - Linking fixes, build output, RC compilation, GN fix, mini_installer, warnings,
    event log, RLZ disable, command IDs, SafeBrowsing fixes, resource list, etc.
- **`#[cromite]`** — Patches from cromite:
  - `Override-the-MV2-deprecation.patch`, `Enable-Global-Privacy-Control.patch` (temporarily disabled)

## Patch Application Order

The full application order during a build is:

1. **External temp** (`thorium/external_temp/`) — conflict-fixed patches from external projects
2. **Upstream fixes** (`thorium/fixes_upstream/`) — crash fixes not yet merged upstream
3. **SafeBrowsing deps + UI fixes** (`thorium/fixes/`) — dependency cleanup, GPC strings, UI removal
4. **External patches** (`series.external`) — ungoogled-chromium-windows prerequisites, Windows patches, cromite patches
5. **Original Thorium patches** (`thorium/original/`) — multi-file patches from Thorium's setup.sh
6. **Merged new patches** (`thorium/new/`) — generated and merged patches grouped by purpose
